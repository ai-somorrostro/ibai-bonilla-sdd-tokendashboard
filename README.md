# ibai-bonilla-sdd-tokendashboard

LLM Token Cost Dashboard - Spec-driven development with feature branches.

Each feature branch implements a single spec:
- `feature.ibai.bonilla.dashboard.display.spec` - Dashboard table display
- `feature.ibai.bonilla.sorting.filtering.spec` - Sorting and filtering
- `feature.ibai.bonilla.visualizations.spec` - Canvas bar charts
- `feature.ibai.bonilla.detail.view.spec` - Tooltips and pin comparison
